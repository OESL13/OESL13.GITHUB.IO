TIENDA SARA - ACTIVIDAD 2
========================

ARCHIVOS
- index.html: página de inicio
- productos.html: galería de productos con búsqueda, filtro por categoría y ordenamiento
- carrito.html: carrito con cantidad editable, eliminación, subtotal, envío y cupón SARA10
- css/estilos.css: estilos visuales
- js/tienda.js: catálogo de 25 productos y lógica del carrito

CÓMO EJECUTAR
1. Descomprime Actividad2_TiendaSara.zip.
2. Abre la carpeta en Visual Studio Code.
3. Abre index.html en el navegador. Recomendado: usar la extensión Live Server.
4. Bootstrap se carga desde CDN; se requiere conexión a Internet para sus estilos.
5. Agrega productos desde Productos y entra a Carrito. Los artículos se guardan en localStorage del navegador.

NOTAS
- Es un prototipo frontend académico. No se conecta a SQL Server ni procesa pagos reales.
- El carrito guarda datos en el navegador mediante localStorage.
- Para la evidencia, captura index.html, productos.html y carrito.html abiertos en el navegador.
